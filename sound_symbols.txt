# The Simpsons (MAME set 'simpsons') - Z80 sound program symbols (072-e03.6g)
#
# Addresses and names only: no game data lives in this file. Format: ADDRESS KIND NAME [...] (see
# tools/core/z80/analysis.py and tools/core/sound_coverage.py). Addresses are the Z80's, 0000-7FFF.
#   func     a function entry (one nothing calls is decompiled too: code the entry points never reach)
#   loop     the main loop's top, a function entry: where the program waits for the board (runtime/src/sound_cpu.c
#            runs the main loop from there while the board's time is ahead)
#   file     PATH: the functions from ADDRESS up to the next file line go to src/sound/PATH.c (the comment of a
#            file's first line is its description)
#   comment FUNCTION TEXT: what the C says above the function; register RN NAME: a register the whole program keeps
#   (game_profile's SOUND_CONTEXT), a global variable in C; unread FUNCTION RN: the function reads RN before setting
#   it only on a path the program never takes (it is no parameter)
#
# The driver (read from the listing, build/sound/listing.s): the 053248 writes a command and its argument to the
# K053260's ports (1FC6-1FC7, which the Z80 reads at FC00-FC01) and raises the Z80's IRQ by reading 1FC4; the Z80
# takes it only in the main loop's four NOPs with interrupts on (sound_command, 0038): F0-FF the self test's answers
# (FC02-FC03) and the reset, 3F and 7F with the argument, the rest a sound and the argument's count of the ones after
# it (start_sound): 00 stops everything, 01-38 an FM effect, 40-7E a PCM effect, 80-AF a song, C0-EF a song after a
# fade. The main loop waits for the YM2151's timer B (some 2 ms), then runs 12 channel records of 50h bytes from F003:
# 8 for the YM2151's channels (chip channel +40 0-7) and 4 for the K053260's voices (8-B), each through the handler it
# keeps at +43 (run_channel, JP (HL) at 0C21) after the music's tick (music_tick); +41 is the sound a record plays
# (bit 7: music), +42 its priority. A PCM voice is keyed on after a HALT that waits for the K053260's NMI (key_on).

# ======== the effects' and the drums' steps ========
# Every effect and every drum routine is a chain of handlers: each runs on its record one main loop pass at a time
# and sets the next one with set_channel_handler (the record's +43), until the last stops the channel (stop_channel)
# or leaves the note ringing (drum_done). The first of a chain is named by the table that starts it: fm_effect_NN
# (effect_handlers[NN], command NN), pcm_effect_NN (effect_handlers_40[NN], command NN), pcm_effect_3f_NN
# (effect_handlers_2[NN], command 3F with the argument NN), pcm_drum_K_N (instrument_routines: kit K, note N) and
# fm_drum_K_N (instrument_routines_low); the rest by the chain they belong to (the first that reaches them) and what
# each does, found from the driver routines it reaches (directly or through the chain's own helpers):
#   note        loads a patch (load_patch) and plays it;       retrigger  keys the channel off and on again (key_on)
#   wait_sample waits for the PCM voice to end (pcm_voice_playing), then ends;  slide  moves the pitch a step at a time
#   pitch       sets a pitch;  transpose  moves the kept pitch without setting it;  fade  changes the volume
#   modulate    the pan or the LFO;  hold  counts down, then ends the sound;  end  ends the sound
#   delay       counts down, then goes on;  setup  sets the record's counters and goes on to the next
#   and for a helper the chain calls: move_pitch (adds DE to the pitch and sets it), set_pitch, set_volume, play,
#   update. A second step of the same kind in one chain is NAME_2, and so on.
