# The Simpsons (MAME set 'simpsons', 4 Players World, set 1) - 053248 program symbols
#
# Addresses and names only: no game data lives in this file.
# Format:  ADDRESS  KIND  NAME  [LAYOUT]   [# comment]
#   KIND: func = function entry, code = code label, data = data label
# Addresses are places of the program: offsets in its 512 KB region (tools/simpsons_rom.py), as kref's traces
# give them: a bank's code at bank x 2000 plus its address in the window (6000-7FFF), the fixed program (8000-FFFF)
# at 078000-07FFFF.
#
# LAYOUT, for data tables that hold code addresses the analysis cannot see the length of
# (tools/core/konami_cpu/analysis.py reads record=, code= and count=):
#   record=N        the table is an array of N-byte records
#   count=N         ... of N records
#   code=A          every record holds a 16-bit code address (a CPU address, in the table's bank) at offset A
# Sizes, offsets and counts are decimal.
#
# The analysis starts at the vectors (the reset at 86CE, the IRQ at 8F43, the FIRQ at 91B2) and finds the code
# without traces, following what the registers and the bank hold into the tables of handlers; the lines here are
# what it cannot work out, each with how it was found (kref --jumps: where a jump through a register went).

# ======== tables of code addresses ========
# two pairs of handler tables by an object's state (its field 2E), each followed by another table of code addresses
# that the code names (LDY #$7A3A, LDY #$7F7C, handed to a routine as data): the analysis stops a table where the
# code names data, but the state runs into the next table, whose first entry is the last state's
# bank 1D's: 629A "LDY #$7A00", 6292 "JMP [A,Y]" (kref --jumps: 03A292 -> 03A5DF, entry 29, which is 7A3A's first)
03BA00  data  bank_1d_states  record=2 count=30 code=0
# bank 1E's: 76FD "LDY #$7F62", 7700 "JMP [A,Y]" (kref --jumps: 03D700 -> 03D88C, entry 13, which is 7F7C's first)
03DF62  data  bank_1e_states  record=2 count=14 code=0

# ======== the stages' objects (tools/data_walk.py: spawn lists) ========
